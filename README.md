# 物理实验室 · 大学物理下互动动画

四间独立的小实验室，对应《大学物理（下）》最常考的四个模块。每个页面都是**单独的 HTML 文件**：离线可开、无需安装、手机可用。

**在线地址：** https://fyjvjvh555-dot.github.io/physics-lab/

## 四个实验

| 实验 | 覆盖内容 | 文件 |
| --- | --- | --- |
| [光的条纹实验室](https://fyjvjvh555-dot.github.io/physics-lab/01-optics.html) | 单缝/双缝/光栅、牛顿环、空气劈尖、薄膜等倾、迈克尔逊、光栅缺级 | `01-optics.html` |
| [光电效应实验室](https://fyjvjvh555-dot.github.io/physics-lab/02-photoelectric.html) | 遏止电压、红限频率、饱和电流、I–V 曲线、四种金属 | `02-photoelectric.html` |
| [驻波实验室](https://fyjvjvh555-dot.github.io/physics-lab/03-standing.html) | 两端固定/一端自由/闭口声管、节点腹点探针、固有频率、共振曲线 | `03-standing.html` |
| [多普勒效应实验室](https://fyjvjvh555-dot.github.io/physics-lab/04-doppler.html) | 靠近/远离、观察者运动、双向、马赫锥、音调轨迹、试听 | `04-doppler.html` |

## 使用方法

1. 打开上面的在线地址，或直接双击本地 HTML 文件；
2. 在画面上拖动滑块改变条件，点“重播/暂停”控制动画；
3. 每页都有「公式解剖」与「考点变式」：先心算，再点选项对答案。

## 说明

- 所有页面均为单文件，无任何外部依赖，断网也能用；
- 动画为了看清，按比例放慢了；页面显示的频率、波长、条纹间距等数值按实时参数计算；
- 界面与文案均为原创，仅参考了 PhET、Falstad 等教学网站的交互思路。
