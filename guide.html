第十二章 · 光学

光的条纹实验室

不只看条纹，还要看懂变式 · 单文件离线网页

简介　光学这一章最难受的地方，是同一个“干涉”在卷子上会换五六种装置：双缝、薄膜、劈尖、牛顿环、迈克耳孙，公式长得像又不一样。这个页面把因果链摆在一起：先在第一展区用单缝、双缝、光栅把“波前怎样叠加成明暗条纹”看清楚，波前动画、屏上条纹和右侧光强曲线三者同步；再进第二展区，把五类考试变式拆开逐个调参。

每个变式都给出实时数值读数与取样功能：点牛顿环上任意半径，直接读到该处是第几级暗环；拖劈尖角度，看条纹间距怎样随厚度变化；换薄膜下方介质，观察反射时相位突变从一次变两次、中心由暗转亮；光栅区可以亲眼区分“缺级”和“几何上根本没有这一级”。每站末尾配一道情境题，答完给出完整思路。

使用方法

  1. 双击 光的条纹实验室.html，用 Chrome / Edge / Firefox 打开即可，无需安装或联网。
  2. 第一展区里切换「单缝衍射 / 双缝干涉 / 光栅衍射」，拖波长、缝宽、缝距、屏距等滑块，盯住波前、屏上条纹、光强曲线三处是否同步变化。
  3. 按画面提示做小挑战（例如把第一处暗纹挪到指定位置），达标后会出现反馈，用来检验是否真的理解了参数关系。
  4. 第二展区点选「牛顿环 / 劈尖 / 薄膜等倾 / 迈克耳孙 / 光栅缺级」，在图上点击取样读数，再用“一键变式”换条件，观察条纹如何整体变化。
  5. 最后做情境题：先自己判断，再看解析对照刚才的图像，把“条纹变密/变疏、中心变亮/变暗”与公式对应起来。

第十三章 · §13-2 光电效应

光电效应实验室

再亮的红光，也打不出电子 · 单文件离线网页

简介　光电效应难在“看不见”：光子有没有打中、电子有没有逸出、反向电压有没有把它们拦住，全凭想象。这个页面把光电管剖开摆在画面中央——光子一个个飞向阴极，能量足够才溅出电子，电子再奔向阳极形成电流；把电压调负，能清楚看到电子“出来了但到不了”。

页面提供铯、钠、钙、锌四种金属（逸出功 2.10 / 2.28 / 2.90 / 4.30 eV），波长 240–800 nm、光子通量 0–100%、阳极电压 −4～+4 V 全部可调。三条图线随参数实时重画：电流–电压看遏止电压、遏止电压–频率看斜率与红限、饱和电流–光强看“更亮只是更多，不是更快”。四道变式题覆盖红限、光强不变性、遏止电压与换金属。

使用方法

  1. 双击 光电效应实验室.html 打开。左侧“你来控制实验”里先选金属，再调波长、光子通量和电压。
  2. 观察中央光电管：有没有光电子逸出、有没有到达阳极、电流表读数是否为零；把电压推到负值，体会“逸出”和“被收集”是两件事。
  3. 切换三种图线，可以直接点图线横轴调参；把波长从 400 nm 慢慢拉到 700 nm，看电流怎样在红限处断掉。
  4. 打开“考点变式”，先选答案，再用“快捷情境”把参数一键切到题设条件，用图线验证自己的判断。
  5. 记住页面底部的说明：金属逸出功为示例值，电流曲线是教学用的理想化模型，用于理解规律而非拟合真实器件。

第十一章 · §11-6 驻波

驻波实验室

让一条绳子，停下来跳舞 · 单文件离线网页

简介　驻波是“两列行波叠加”的结果，但课本上的静态图很容易让人误以为波真的停住了。页面同时画出向右传播的入射波、向左传播的反射波，以及它们叠加后的合成波：调慢或单步，就能看到合成波在原地上下振动，而某些点始终不动。

在波形上任意位置点一下，就放下一个探针，实时显示该点的振幅与瞬时位移，并判断它靠近波节还是波腹。边界可在「两端固定」「一端固定一端自由」「一端封闭的声管」之间切换，模态、弦长、张力、线密度、声速、振幅都可调；下方给出固有频率柱状图与阻尼单模共振曲线，把“为什么只能取这些频率”和“驱动频率接近固有频率时振幅最大”连起来。五道变式题覆盖模态计数、奇次谐波、张力四倍、相邻波腹反相、声管开口是位移波腹。

使用方法

  1. 双击 驻波实验室.html 打开。先在右侧“① 先选边界”里挑一种边界，注意端点处是波节还是波腹。
  2. 拖“模态序号 / 有效长度 / 弦的张力 / 线密度”，观察合成波与下方波速、波长、固有频率读数如何联动；想验证 f ∝ √T，把张力从 20 N 调到 80 N 即可。
  3. 点主波形放下探针，再按“暂停 / 单步 / 慢放”，看探针处的点怎样振动；靠近波节时振幅读数接近零。
  4. 切到“固有频率 / 驱动频率与共振”图解，点柱子切换模态，或拖驱动频率看阻尼响应曲线。
  5. 切到声管模式后可点“试听”听到对应频率（默认静音）；最后做五道变式题，先心算再看解。

第十一章 · §11-7 多普勒效应

多普勒效应实验室

救护车驶过，为什么音调会“掉”下来 · 单文件离线网页

简介　多普勒效应最容易被记成一条“靠近变高、远离变低”的口诀，一遇到观察者也在动、或者两者相向而行，符号就乱了。这个页面把声源真的放到马路上：俯视视角下，救护车一边行驶一边发出声波，青色圆圈是同一时刻发出的波阵面——车头前的被挤密，车尾后的被拉开，听者头顶实时显示“你听到多少赫兹”。

下方“音调轨迹”把听到的频率画成曲线，驶过瞬间那一下台阶式下跌看得清清楚楚。页面还给出公式解剖（把当前数值直接代入 f′ = f₀(v ± v₀)/(v ∓ vₛ)）、四个方向的符号表，以及五个考点：靠近、驶过之后、观察者迎着声源、双向接近、超音速马赫锥（把声源速度拖过 340 m/s 就会画出锥面与锥角 θ，满足 sin θ = v / vₛ）。

使用方法

  1. 双击 多普勒效应实验室.html 打开。页面默认以 700 Hz、90 m/s 的救护车自动演示。
  2. 在右侧拖“声源速度”“观察者速度”，点“重播驶过”，让声源从听者身边经过；盯住青色圆圈的疏密变化。
  3. 看听者头顶的频率气泡和“音调轨迹”，找到驶过瞬间的跳变；再用“试听音调”听一遍（需点击，默认静音）。
  4. 到第二展区对照公式解剖：滑块一动，靠近与远离两行数值同时重算，用来检查自己的符号有没有写反。
  5. 在第三展区点选五个考点之一，参数会自动切到题设条件（如 2 马赫），先预测再选答案，最后看完整思路。
